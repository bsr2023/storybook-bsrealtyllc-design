# BS Realty Design System

BS Realty Design System is the in-house component library built to standardize and accelerate
UI development across all BS Realty products — web, mobile, and insurance services.

All components are built from the official Figma designs and are shared across:
- `bsrealty-web-main`
- `insurance-web`
- `auth-service`

---

## Installation

### Step 1 — Link the package locally

From the `my-storybook-app` folder, run:

```bash
npm link
```

Then inside each project that needs the components:

```bash
# inside bsrealty-web-main
npm link my-storybook-app

# inside insurance-web
npm link my-storybook-app

# inside auth-service
npm link my-storybook-app
```

### Step 2 — Import components

```tsx
import { BSRealtyButton } from 'my-storybook-app';
import { BSRealtySearchbar } from 'my-storybook-app';
import { BSRealtyPropertyCard } from 'my-storybook-app';
```
